# Shaperrific

Adds simple but attractive background shapes to your pages. With Color
module support.

Five different shapes (circle, polygons, ellipse) and three color presets allow
immediate customization without any effort.

## Installation

- Install this theme using the official [Backdrop CMS instructions](https://docs.backdropcms.org/documentation/skin-with-themes)

Shaperrific is a sub theme of [Bedrock](https://backdropcms.org/project/bedrock),
so you'll also need the base theme.

Go to admin/appearance, enable and set Shaperrific as default theme. It's not
necessary to also enable the base theme.

Then switch over to the theme settings on admin/appearance/settings/shaperrific.

If the Color module's turned off, you can change the background shape.

If the Color module's turned on you can additionally configure all colors - or
use one of the presets, assisted by a dynamic preview of the home page.

## Dependencies
